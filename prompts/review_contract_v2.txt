Review response contract version 2: return no more than 30 findings, and also return findings_complete (boolean). Examine the complete article and metadata before assigning the score and verdict. The response limit never permits overlooking a substantive error or raising the score to make the result fit.

Prioritize critical findings, then major findings, then minor findings. Combine repeated instances only when they are the same underlying defect, retaining every affected location and the concrete source/translation evidence needed to repair them. Keep findings concise and actionable. Do not invent a finding merely to describe a reporting limit.

Set findings_complete=true only when all substantiated findings identified in this review are represented without omitted locations or evidence. If all identified findings cannot fit in 30 entries and the available response space, return the most serious substantiated findings, set findings_complete=false, and set passed=false. Do not claim the report is complete by silently dropping remaining findings. This marker describes whether the report includes what you found; it is not a claim that every possible error has been discovered. Return the existing score, passed, and findings fields as well. A report marked incomplete cannot approve publication.
